
# Plant Life — SwiftUI Prototype

A lightweight iPad/iPhone SwiftUI prototype for early-elementary learners. It demonstrates a mocked plant-discovery flow, supported versus unsupported identification results, a virtual garden, four care choices, child-friendly feedback, and five visual growth stages.

## Run it in Xcode

1. Open [PlantLifePrototype.xcodeproj](/Users/meriermerlont/Documents/ChatGPT/Plant%20Life/PlantLifePrototype.xcodeproj) in Xcode.
2. Select an iPad simulator and press Run.

The camera button intentionally returns a mocked recognition result. Replacing that action with `PhotosPicker` or a camera capture plus an image-recognition service is the natural next implementation step.
